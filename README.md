Project Overview

AVERA is a modern educational website designed as a thoughtful learning space where students can explore courses, connect with mentors, and build practical skills for their future.

The website focuses on a clean editorial-style interface combined with subtle 3D visual elements to create a more engaging and memorable learning experience.

live demo : [https://avera-sepia.vercel.app/](https://avera-sepia.vercel.app/)

Technologies Used
HTML5 — Used to create the complete structure and content of the website.
CSS3 — Used for the visual design, layout, responsive styling, animations, buttons, cards, and 3D-inspired effects.
JavaScript (Vanilla JS) — Used for interactive features, animations, navigation behaviour, 3D interactions, and the application form popup.
Google Fonts — Used for the website typography and custom font styling.
Responsive Web Design — CSS media queries are used to make the website work on desktop, tablet, and mobile screens.

How to Run

Open `index.html` directly in any modern browser, or serve the folder locally:

```bash
npx serve .
```
You can also use VS Code Live Server:

Open the project folder in VS Code.
Install the Live Server extension.
Right-click `index.html`.
Select Open with Live Server.
The website will open in your browser.

No build step, no dependencies, and no external JS libraries — everything is plain HTML/CSS/JS plus Google Fonts loaded via CDN.

 Note on Design Choices

AVERA uses a clean, modern editorial-style design with bold typography, warm tones, subtle 3D elements, and smooth animations. The two-column hero layout and interactive visuals create a balanced, engaging learning experience while keeping the interface simple and user-friendly.
